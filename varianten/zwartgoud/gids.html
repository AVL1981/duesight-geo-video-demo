Hoe deze site is gebouwd

Deze site is geen handwerk maar compiler-output: één JSON-config in, een deterministische, contract-gecheckte site uit. Dit is de keten.

Van config naar bewijs

1

Config

Eén JSON-bestand beschrijft merk, pagina's, secties en camerarollen — meer input is er niet.

2

Compiler

De regie-taal wordt vertaald naar scroll-choreografie met drie vangnetlagen, tot statisch aan toe.

3

Contract

Twintig-plus checks blokkeren de build bij claimtaal, externe requests, ontoegankelijkheid of een gestripte designlaag.

4

Receipt

Elke build levert sha256-hashes per bestand. Identieke config geeft byte-identieke output — reken het na.

De harde garanties

0externe requests — alles is meegeleverd
20+contractchecks per build
3motion-vangnetlagen, tot statisch aan toe
sha256per bestand, in het build-receipt
